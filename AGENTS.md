# Project instructions

- Never run `git config --global`; this is a shared machine.
- Before the first commit of each session, confirm the current `git config user.name` and `git config user.email` with the user, even if values are present.
- Read CONTRIBUTING.md before changing information. Edit `data/` for venue/course facts and `site/` for UI; do not edit generated `dist/`.
- Run `npm run check` and `npm run build` before publication.
- Keep sourced facts, direct quotes, estimates and unknown values distinct. Never infer jump clearance from a weather model or a license alone.
- Keep UI copy functional, without marketing language. Chinese and English interfaces should each use consistent language.
- Keep USPA outdoor progression separate from IBA indoor progression and from future sports' certification models.
